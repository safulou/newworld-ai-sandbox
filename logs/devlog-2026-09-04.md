### ⚠️ [Note] 技術重點與地雷
- SQLite3 的 Promise 封裝需自建包裝函式處理 `this` 綁定（包含 `this.lastID` 與 `this.changes`），不能直接使用 Node.js `util.promisify` 以避免型別簽名衝突。
- Web Audio API 在部分瀏覽器中需要於首次使用者互動（Click / Keydown）後呼叫 `audioContext.resume()` 方可發聲，`SoundEngine` 已內建自動回復狀態檢查。

### 🎯 [Decision] 關鍵決策
- **空間生成架構採用 Procedural DSL 取代單點 Block JSON**：
  - 理由：單點 Block 序列化需耗費數萬 Token 且容易因模型幻覺產生破洞；DSL 巨集指令兼具可解釋性、低延遲、高精度，且可在前端 10ms 內編譯展開。
  - 影響：大幅節省 API 成本與等待時間，並支援極為複雜的多層次大型建築。
