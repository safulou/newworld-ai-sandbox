### ⚠️ [Note] 技術重點與地雷
- **Web Speech API 瀏覽器異構性**：
  - 各瀏覽器的 `speechSynthesis.getVoices()` 可能是異步加載，需監聽 `voiceschanged` 事件並在發話時進行動態回退檢索。
- **語音文本過濾的重要性**：
  - AI NPC 的回覆常包含代碼塊、Markdown 標題與表情符號，若未進行正則清洗，瀏覽器語音會念出「井號井號」、「反引號」等生硬字詞，嚴重破壞元宇宙沉浸感。
- **測試環境無瀏覽器原生物件保護**：
  - 在 Vitest (Node.js) 環境下執行單元測試時，`localStorage` 與 `window.dispatchEvent` 必須做 `typeof window !== 'undefined'` 與 `typeof localStorage !== 'undefined'` 判斷，確保 CI/CD 與測試環境無縫通過。

### 🎯 [Decision] 關鍵決策
- **首選瀏覽器原生 Web Speech API**：
  - 降低玩家體驗門檻，無需設定任何付費 API Key 即可享有完整語音對話；同時預留 OpenAI TTS 介面，供追求極致擬真神經聲線的高階玩家選用。
- **非侵入式 3D 頭頂光環與近距離問候**：
  - 透過 Three.js 幾何光環與面罩發光直接反映說話狀態，無需複雜的臉部 Blendshapes，兼顧體素風格美學與極致渲染幀率。

### ⚠️ [Note] 技術重點與地雷
- **Boids 群聚算法的邊界限制**：
  - 量子蝴蝶若只計算 Separation/Alignment/Cohesion，長時間運算會逐漸漂向無限遠。設定球形軟邊界反向引力 (`distFromCenter > boundsRadius`)，讓蝶群始終穩定盤旋在花草棲息地上空。
- **音符方塊邊緣觸發機制**：
  - 電路 BFS 傳導每幀都會遍歷連通網，若直接觸發音符會導致每幀音爆。在 `CircuitEngine` 中維護 `poweredNoteBlocks: Set<string>`，僅在信號從 0 變 1（上升沿）時單次觸發，確保節奏乾淨準確。

### 🎯 [Decision] 關鍵決策
- **雙模式自由無縫切換**：
  - 玩家可在 HUD 上隨時於「創造模式 (God Mode)」與「生存冒險模式 (Survival)」間即時切換，既保有自由建築的無拘無束，又能隨時體驗光劍砍殺、護盾回充與地下城闖關的刺激感。
- **NPC 代工結合全息投影**：
  - 玩家不再只是單純按下按鈕瞬間變出建築，更可選擇讓 AI NPC 工人伴侶親自前往該座標，揮汗逐塊鋪設，極大加深了人機協同的元宇宙沉浸感。
