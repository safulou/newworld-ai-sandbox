### ⚠️ [Note] 技術重點與地雷
- **Web Speech API 瀏覽器異構性**：
  - 各瀏覽器的 `speechSynthesis.getVoices()` 可能是異步加載，需監聽 `voiceschanged` 事件並在發話時進行動態回退檢索。
- **語音文本過濾的重要性**：
  - AI NPC 的回覆常包含代碼塊、Markdown 標題與表情符號，若未進行正則清洗，瀏覽器語音會念出「井號井號」、「反引號」等生硬字詞，嚴重破壞元宇宙沉浸感。
- **測試環境無瀏覽器原生物件保護**：
  - 在 Vitest (Node.js) 環境下執行單元測試時，`localStorage` 與 `window.dispatchEvent` 必須做 `typeof window !== 'undefined'` 與 `typeof localStorage !== 'undefined'` 判斷，確保 CI/CD 與測試環境無縫通過。

### 🎯 [Decision] 關鍵決策
- **首選瀏覽器原生 Web Speech API**：
  - 降低玩家體驗門檻，無需設定任何付費 API Key 即可享有完整語音對話；同時預留 OpenAI TTS 介面，供追求極致擬真神經聲線的高階玩家選用。
- **非侵入式 3D 頭頂光環與近距離問候**：
  - 透過 Three.js 幾何光環與面罩發光直接反映說話狀態，無需複雜的臉部 Blendshapes，兼顧體素風格美學與極致渲染幀率。
