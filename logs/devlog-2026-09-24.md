### ⚠️ [Note] 技術重點與地雷
- **Windows / WSL 跨系統檔案 I/O 耗時考量**：
  - 在 WSL 環境下讀取 `/mnt/c/` 磁碟時，`vue-tsc` 與 `vite build` 耗時約 35 秒，執行前應預留足夠超時時間，避免背景任務被誤判逾時。
- **純代碼 Web Audio 合成器性能保證**：
  - 音符方塊使用 Web Audio API 即時振盪器計算，不載入任何外部音頻檔案，即便高頻觸發亦不占用網路帶寬或磁碟空間。

### 🎯 [Decision] 關鍵決策
- **雙項目規範一致化**：
  - 將 `newworld-study-room` 的優秀工程實踐（CLAUDE.md、收尾流程、純代碼 Web Audio）無縫移植至 `newworld-ai-sandbox`，統一跨專案心智模型。
- **無侵入式漸進式功能整合**：
