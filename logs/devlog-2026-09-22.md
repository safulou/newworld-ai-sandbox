# devlog 2026-09-22 (WebRTC Spatial Voice Chat & Arena Minigames Expansion: Laser Tag & Voxel Snake)

## Session 摘要
本檔記錄 2026-09-22 執行並完成 **P0（WebRTC 3D 空間語音通話）** 與 **P1（元宇宙競技場擴充：PvP 激光槍戰 & 3D 體素貪吃蛇）** 兩大旗艦任務：
1. **P0 空間語音**：針對 `newworld-ai-sandbox` 專案全面實作多人 WebRTC 3D 空間語音 (Spatial Voice Chat) 系統。結合現有 `spatialAudio.ts` 的 Web Audio API 3D HRTF PannerNode、聽者朝向向量與空間距離衰減計算，透過後端 Socket.IO 信令伺服器（WebRTC Mesh Signaling）實現隨玩家 3D 座標與視角朝向動態衰減的即時語音通話；同時打造具備動態 VU 音量表、3D 空間音訊測試信標 (Test Beacon)、周圍玩家距離與音量調節的賽博龐克風格語音控制面板 (`SpatialVoiceModal.vue`)、HUD 語音即時狀態快捷膠囊、3D 人物頭頂發話光環，並順利推送到 GitHub `origin/main`。
2. **P1 競技場小遊戲擴充**：
   - **賽博 PvP 激光槍戰 (Cyber Laser PvP Arena)**：30x30 封閉力場戰場、4 座狙擊高塔、量子核心柱、引力彈跳墊、5 架自主巡邏 AI 戰鬥無人機、電漿爆破槍擊中判定、爆炸碎屑與連擊加分系統（60 秒計時賽）。
   - **3D 體素貪吃蛇 (3D Voxel Snake Arena)**：24x24 賽博邊界網格、奔跑長蛇體素尾身即時生成追隨、隨機量子能量果生成與吞噬音效、自身尾巴與邊界力場碰撞判定。
   - **競技場即時 HUD 記分看板**：頂部浮動顯示競技場模式、倒數時間、即時得分、連擊數與一鍵退出挑戰。
   - **成就系統登錄**：「量子通訊網」、「賽博神射手」、「量子貪食蛇」三大專屬成就與全套單元測試，型別檢查 0 Error / 0 Warning 通過。

## Session 區塊

### 📋 任務目標
- **WebRTC 3D 空間語音通訊架構 (P0)**：
  1. 後端 Socket.IO 信令服務支援：註冊 `voice-join`、`voice-peer-list`、`voice-peer-joined`、`voice-signal`、`voice-mute-toggle`、`voice-leave` 與中繼轉發。
  2. Web Audio API 3D 空間立體聲擴充：擴充 `SpatialAudioEngine`（`spatialAudio.ts`）支援攝影機 3D 視角朝向向量（Forward / Up）、MediaStream 3D HRTF PannerNode 處理管線與語音獨立 Submix 匯流排。
  3. WebRTC Mesh 語音引擎：建立 `SpatialVoiceEngine`（`spatialVoice.ts`），支援本機麥克風動態捕捉、VAD 發話音量偵測（RMS VU Meter）、P2P PeerConnection 連線網狀拓撲、斷線重連與優雅降級（無麥克風時自動切入收聽模式）。
  4. 3D 空間音訊測試信標 (Spatial Audio Beacon Test)：內建單人虛擬 3D 聲源信標，支援一鍵在前方生成發聲源，即使單人亦能親耳體驗雙耳立體聲相（HRTF Stereo Panning）與距離衰減。
  5. 前端互動 UI 與 3D 視效：開發 `SpatialVoiceModal.vue`（按 `X` 或 `F8` 開啟）、HUD 語音即時狀態快捷條、3D 人物頭頂發話光環（Voice Halo）。
- **競技場小遊戲關卡擴充 (P1)**：
  1. 實作賽博 PvP 激光槍戰競技場 (`minigames.ts`：`generateLaserArena`)，包含戰鬥無人機群、高塔跳躍墊、電漿發射器射擊碰撞偵測與 60 秒計時賽。
  2. 實作 3D 體素貪吃蛇競技場 (`minigames.ts`：`generateSnakeArena`)，包含量子能量果吞噬機制、動態尾身體素生成、尾身碰撞與邊界出界判定。
  3. 在 HUD 實作即時競技場看板 (`minigame-hud-bar`)，即時呈現倒數、擊破數/果實數、連擊倍率與分數。
  4. 擴充 `MinigamesModal.vue` 支援 4 大關卡選擇，並登錄「賽博神射手」與「量子貪食蛇」成就。

### ⚠️ [Note] 技術重點與地雷
- **體素材質型別約束**：
  - 小遊戲地形生成時，方塊材質須符合 `BlockType` 定義，例如使用 `cyber_plating` 與 `concrete`，以確保 `world.setBlock` 與渲染引擎完全相容。
- **貪吃蛇尾身節點優雅回收**：
  - 當尾身長度超出 `snakeLength` 時，透過 `snakeGroup.remove` 與 `geometry.dispose()` 即時釋放 WebGL 幾何資源，防止記憶體洩漏。
